# P01 · 数字逻辑：从 NAND 到 4-bit 加法器

**计划：**14 天；**硬件：**无（浏览器模拟器 / 逻辑测试）；**先修：**二进制基本阅读即可；**状态以 `learning/state.json` 为准**。

## 为何做这个

真实 NPU 的乘法、加法、控制和寄存器都建立在可组合的数字逻辑之上。P01 不只是背逻辑门，而是能自己预测输出并解释一条进位链。核心演示：4-bit Ripple Carry Adder（可串行传递进位的加法器），对 0–15 输入正确产生 5-bit 结果。

## 两周小步（每次仅推进一个 Step）

| ID | 建议日 | 学员亲手做 | 当步才补充的概念 | 可验收证据 |
|---|---|---|---|---|
| P01-S01 | D1–2 | 填半加器 4 行真值表，解释 1+1=10₂ | binary、sum/carry | 手写/聊天独立回答与解释 |
| P01-S02 | D3–4 | 用 AND/XOR 实现 Half Adder | boolean truth table、XOR | 逻辑图或 Nand2Tetris HDL、全组合测试 |
| P01-S03 | D5–6 | 设计 Full Adder，加入 carry-in | 串联两个 Half Adder | 8 种输入验证、说明 carry-out |
| P01-S04 | D7–9 | 串接 4 个 Full Adder | ripple propagation、位宽 | 4-bit→5-bit 电路和测试 |
| P01-S05 | D10–12 | 覆盖 0、1、7、8、15 等边界与所有输入对 | exhaustive test、延迟直觉 | 256 组输入、结果一致日志 |
| P01-S06 | D13–14 | 独立画出数据流和一个进位案例，整理报告 | 组合路径与传播延迟 | 答辩解释 + 实验报告 |

**P01-S01 尚未验收。** 此前聊天出现过半加器互动表格，但没有用户回传验证结果。

## 最小交付（MVD）

- 逻辑设计文件（Nand2Tetris HDL / 清晰门级图）或等价可运行逻辑仿真。
- 半加器与全加器真值表；4-bit adder 测试，覆盖输入 `A,B∈[0,15]` 全组合；若有 carry-in 也要覆盖 0/1。
- 证明输出的 5-bit 结果可表示 15+15=30，不丢弃最高进位。
- 学员回答：为何 XOR 是 Sum、AND 是半加器 Carry？为什么 Ripple Carry 可能变慢？
- `projects/P01-digital-logic/evidence/` 中的最终报告（可从模板复制），教师审核后才 PASS。

## 可选挑战

仅由 NAND 构造 XOR / 4-bit ALU；比较进位链长度与传播延迟。挑战未做不影响 MVD。

## 提前防错

不要只用 0+0、1+1 两种样本；不要把 Nand2Tetris 教学 HDL 当做已验证可综合 Verilog；逻辑模拟不是实体芯片电压/时序测量。

## 交接给 P02/P03

学生应能说出组合逻辑没有时钟、进位如何在级间传递；保存加法器的 input/output 接口、测试和亲自解释。P03 将把它改写成可综合 RTL。
