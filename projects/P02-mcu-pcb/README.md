# P02 · MCU + PCB：把逻辑连接到真实世界

**计划：**14 天；**资源：**ESP32 开发板/USB 低压供电，面包板与电子实验室（按实际可用性），Mac + KiCad。**P01 基础：**电平与布尔逻辑。

## 任务概述

构建一个小系统：按钮输入→LED 状态切换→UART 输出状态；随后用 KiCad 设计一个合理的外围 PCB（按钮、LED、限流电阻、连接器、公共地线）。在学完 P02 后，应能分辨 MCU 固件、PCB 布线和 MCU 芯片内部 CPU 逻辑这三件事。

## MVD 验收（不强制买成品 PCB）

- 开发板/实物环境可用时：按钮每次有效按压切换 LED 状态，串口记录变化；若硬件不可用，明确标注 simulation-only/blocked，不伪造实测。
- KiCad 可编辑原理图、PCB，ERC/DRC 无未解释的重大错误；注明是否实际制造。
- 学员能解释：为什么 LED 不能直接无阻接 GPIO？为什么需要公共地线？UART 数据在什么引脚及什么电平传输？
- 最终报告列实际供电、电阻、引脚、板版本、测试次数、失败与复测证据。

## 安全 / 设备

仅用实验室允许的 USB/低压供电，不直接接市电；不随意把 5V 接入 3.3V 引脚。UKM 刻板机不保证开放或免费，PCB 可留在 CAD/DRC 阶段。可把复杂环境或 PCB 出图重复性操作交 Codex，但电路连接与设计决策要由学员自己解释。

## 交接
